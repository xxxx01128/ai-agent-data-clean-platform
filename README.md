# AI智能体数据清洗平台（Flask）
## 项目简介
面向供应链、风控场景的AI Agent数据清洗工具，用户上传脏数据文件，使用自然语言描述清洗需求，由大模型自动生成Python清洗代码、执行数据处理，输出清洗结果与可视化看板。
适配大宗供应链AI智能体落地场景。

## 技术栈
Python Flask | ECharts | 大模型Agent | 提示词工程

## 核心功能
1. 支持CSV脏数据文件上传
2. 自然语言输入清洗规则
3. AI自动生成、在线执行清洗代码
4. 数据可视化看板，多维度查看数据
5. 导出清洗完成文件
