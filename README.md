# AI智能体数据清洗平台（Flask）
## 项目简介
面向供应链、风控场景的数据清洗工具，用户上传脏数据文件，执行数据处理，输出清洗结果与可视化看板。


## 核心功能
1. 支持CSV脏数据文件上传
2. 数据可视化看板，多维度查看数据
3. 导出清洗完成文件

## 本地运行方式
1. 安装依赖：pip install -r requirements.txt
2. 启动项目：python app.py
3. 浏览器访问访问：[http://127.0.0.1:5000](http://127.0.0.1:5000)
